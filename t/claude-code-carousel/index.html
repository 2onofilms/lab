How I made an animated carousel with Claude Code (no After Effects)

Eight slides, each one an 8-second video that loops without a visible cut. You work in the Claude desktop app, in the Code tab, and just type prompts. No terminal needed. Here is the full guide, step by step.

01

Get the Claude app and set up

  1. Download the Claude app from claude.com/download (Mac or Windows) and sign in with your Claude account.
  2. Click the Code tab at the top of the app.
  3. Choose an empty folder for your project (create a new one, for example my-carousel).
  4. Paste this prompt in the chat:
Prompt · setup
Set up a new HyperFrames project here and check that Node.js 22+ and FFmpeg are installed.
Claude may ask permission to run commands or install things. Read what it wants to do, then allow it. If Node.js or FFmpeg are missing, it tells you how to install them (see the table above).
02

Create YOUR design system

Paste this prompt in the Code tab. It asks you 5 questions and saves your answers as design.md, so all 8 slides look like one piece.

Prompt · design system
Before any slide, help me create my design system. Ask me 5 questions (mood, audience, colours, fonts, references), then save the answers as design.md. Every slide must follow it.
03

Build the slides

Replace [topic] with your subject and paste it in the Code tab.

Prompt · build 8 slides
Now build 8 slides about [topic] as HyperFrames compositions in this project, one HTML file per slide, following design.md. Slide 1 a hook under 10 words, slides 2-6 one step each, slide 7 a call to action, slide 8 a recap. Each slide an 8-second loop, text readable from the first frame.

You'll get: 8 HTML files in your project. Claude writes them, you don't. To see them, ask:

Prompt · preview
Open a preview in my browser.

Change things by asking

You never edit code. Just tell Claude what to change:

Prompt · bigger titles
Make the titles bigger on all slides, keep them inside the safe margins.
Prompt · change a colour
Change the accent colour to [colour] on every slide and update design.md.
Prompt · fix a slide
Slide 4 has text running off the edge. Fix it and show me the result.
04

Render and post

Ask Claude to render everything:

Prompt · render
Render all 8 slides to MP4 into a folder called export.

Your videos land in the export folder inside your project. To post: open Instagram, tap New post, select the 8 videos in order. The first frame of the first video is the cover.

05

Tips (optional)

Not steps. These make the result look more professional, and you can ask Claude for each one.

  • Seamless 8 s loop. Instagram repeats carousel videos, so every moving value should return to where it started at exactly 8 seconds.
  • Text still from frame 0. No entrances or fades on text. Only background elements (glows, particles, grids) move.
  • Motion blur. Ask Claude to render at 240 fps and blend the frames down to 60 fps with ffmpeg for a filmic look.
  • Check the seam. Watch the video loop a few times; if you see a jump, ask Claude to find it.
06

Troubleshooting

  • Claude answers with text instead of files. Tell it: "Write the files in this project folder." Make sure you picked a folder in the Code tab.
  • Node or FFmpeg missing. Ask Claude: "Check that Node.js 22+ and FFmpeg are installed, and tell me how to install anything missing." Install what it lists (links in the table above), restart the Claude app, and ask again.
  • Preview is blank or render fails. Ask Claude: "Run npx hyperframes doctor and fix what it reports", then "Open a preview in my browser."
  • Videos too big to upload. Ask Claude: "Re-render the slides smaller, under 30 MB each."

Prefer the terminal?

Show the terminal commands (optional)

Everything above also works with the Claude Code command line. Install it (Mac, Linux or WSL):

Terminal · Mac / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash

Windows PowerShell:

Terminal · Windows PowerShell
irm https://claude.ai/install.ps1 | iex

Create the project and start Claude Code inside it (it asks you to log in once, in your browser):

Terminal · project
npx hyperframes init my-carousel
cd my-carousel
claude

Check the tools:

Terminal · check
node -v
ffmpeg -version
claude --version

Preview and render one slide by hand:

Terminal · preview and render
npx hyperframes preview
npx hyperframes render -c compositions/slide-1.html -o export/slide-1.mp4
