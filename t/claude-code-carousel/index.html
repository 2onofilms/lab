How I made an animated carousel with Claude Code (no After Effects)

Eight slides, each one an 8-second video that loops without a visible cut. Everything runs on my own computer. Here is the full guide, step by step.

What you'll make

Eight slides for an Instagram carousel, each one an 8-second looping video, made by typing prompts in Claude Code. No After Effects, nothing to draw by hand.

Tools you need

ToolWhat it isGet it
Claude CodeThe AI that writes the project. Needs a Claude Pro plan or higher.code.claude.com/docs/en/setup
Node.js 22+Runs HyperFrames. Download the LTS version.nodejs.org
FFmpegVideo encoder. Windows: winget install ffmpeg. Mac: brew install ffmpeg.ffmpeg.org/download.html

Check it's installed

Open a terminal (PowerShell on Windows, Terminal on Mac) and run these. Each should print a version number.

Terminal · check
node -v
ffmpeg -version
claude --version
01

Install and create the project

Install Claude Code. Mac, Linux or WSL:

Terminal · Mac / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash

Windows PowerShell:

Terminal · Windows PowerShell
irm https://claude.ai/install.ps1 | iex

Then create the project and start Claude Code inside it:

Terminal · project
npx hyperframes init my-carousel
cd my-carousel
claude
First run: Claude Code opens your browser so you can log in once. After that it stays logged in.
02

Create YOUR design system

Type this prompt in Claude Code, in the terminal. It asks you 5 questions and saves your answers as design.md, so all 8 slides look like one piece.

Prompt · design system
Before any slide, help me create my design system. Ask me 5 questions (mood, audience, colours, fonts, references), then save the answers as design.md. Every slide must follow it.
03

Build the slides

Replace [topic] with your subject and paste it into Claude Code.

Prompt · build 8 slides
Now build 8 slides about [topic] as HyperFrames compositions in this project, one HTML file per slide, following design.md. Slide 1 a hook under 10 words, slides 2-6 one step each, slide 7 a call to action, slide 8 a recap. Each slide an 8-second loop, text readable from the first frame.

You'll get: 8 HTML files in your project. To see them, run this in a second terminal (inside my-carousel) and open the address it prints:

Terminal · preview
npx hyperframes preview

Change things by asking

You never edit code. Just tell Claude what to change:

Prompt · bigger titles
Make the titles bigger on all slides, keep them inside the safe margins.
Prompt · change a colour
Change the accent colour to [colour] on every slide and update design.md.
Prompt · fix a slide
Slide 4 has text running off the edge. Fix it and show me the result.
04

Render and post

Ask Claude to render everything:

Prompt · render
Render all 8 slides to MP4 into a folder called export.

Manual option, one slide at a time (repeat for each slide):

Terminal · render one slide
npx hyperframes render -c compositions/slide-1.html -o export/slide-1.mp4

Your videos are in my-carousel/export/. To post: open Instagram, tap New post, select the 8 videos in order. The first frame of the first video is the cover.

05

Tips (optional)

Not steps. These make the result look more professional, and you can ask Claude for each one.

  • Seamless 8 s loop. Instagram repeats carousel videos, so every moving value should return to where it started at exactly 8 seconds.
  • Text still from frame 0. No entrances or fades on text. Only background elements (glows, particles, grids) move.
  • Motion blur. Ask Claude to render at 240 fps and blend the frames down to 60 fps with ffmpeg for a filmic look.
  • Check the seam. Watch the video loop a few times; if you see a jump, ask Claude to find it.
06

Troubleshooting

  • "command not found: claude" (or node). Close the terminal and open a new one. If it still fails, check that the install folder is in your PATH.
  • Node version too old. Run node -v. If it is below 22, install the current LTS from nodejs.org and restart the terminal.
  • ffmpeg not found. Install it (winget install ffmpeg on Windows, brew install ffmpeg on Mac), then restart the terminal and run ffmpeg -version.
  • Preview is blank or render fails. Ask Claude: "Run npx hyperframes doctor and fix what it reports."
  • Videos too big to upload. Ask Claude: "Re-render the slides smaller, under 30 MB each."
  • Claude replies with text instead of files. Tell it: "write the files in this project".
